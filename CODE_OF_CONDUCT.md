# Code of Conduct

## Naše pravidla

Aby bylo přispívání příjemné pro všechny, očekáváme, že každý:

- je zdvořilý a respektující,
- přijímá konstruktivní kritiku,
- se zapojuje s ohledem na ostatní.

Nepřípustné je obtěžování, urážlivé komentáře nebo osobní útoky jakékoli formy.

## Vykázání

nebo varování, v závažných případech dočasný nebo trvalý zákaz přispívání.
