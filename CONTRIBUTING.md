# Přispívání

Díky, že přispíváš!

## Vývoj

```bash
pnpm install
pnpm dev
```

Před pushem nech změny projít kontrolami:

```bash
pnpm check
```

## Větvení a commit message

- Větev pojmenuj popisně: `feat/uvoleni-exportu`, `fix/empty-cart`.
- Commit message používej Konvenci Conventional Commits, např. `feat: přidat přihlášení přes Google`.

## Pull request

1. Vytvoř větev z `main`.
2. Změň kód a doplň testy.
3. Otevři PR a popiš, co a proč měníš.
4. CI musí projít (lint, typecheck, testy, build).
